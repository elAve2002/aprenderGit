GitHub

Inicializar un repositorio local:
- Crear una carpeta y abrir la terminal.
- $ git init

Crear un repositorio remoto
- URL: https://github.com/elAve2002/aprenderGit.git 

- agregar nombre y mail para identificar repo local
- $git config user.name "<<tu nombre>>"
- $git config user.email "<<mail de la cuenta git>>"

- agregar el repo remoto
- git remote add origin "URL_de_repo_git"
